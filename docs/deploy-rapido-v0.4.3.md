# Deploy rápido — Clara BPO v0.4.3

1. Commit/push de toda a pasta da v0.4.3 no GitHub.
2. Aguarde o Railway concluir `npm run install:all && npm run build`.
3. Abra `/api/health` e confirme `version = 0.4.3`.
4. Entre em uma empresa de teste.
5. Faça upload dos quatro PDFs de referência com qualquer competência selecionada.
6. Confira a Central de Arquivos e os meses de maio/julho/agosto.
7. Se algum arquivo cair em revisão, o popup agora exibirá o motivo individual para diagnóstico.
