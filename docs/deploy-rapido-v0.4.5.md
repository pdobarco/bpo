# Deploy rápido — Clara v0.4.5

1. Substitua o conteúdo do repositório pelo conteúdo deste ZIP.
2. Commit/push no GitHub conectado ao Railway.
3. Aguarde build e deploy.
4. Abra `/api/health` e confirme `version: 0.4.5`.
5. Faça recarga forçada no navegador (`Ctrl+Shift+R`).
6. Confirme `Clara BPO · v0.4.5` no rodapé.
7. Reenvie os quatro PDFs que haviam falhado. A v0.4.5 reconhece os registros anteriores como tentativas falhas e permite o reprocessamento.
